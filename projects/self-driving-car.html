About These Projects

This collection showcases my work from the Udacity Self-Driving Car Engineer Nanodegree program. Each project focuses on fundamental concepts in autonomous vehicle technology, including computer vision, sensor fusion, localization, path planning, and control systems.

These projects demonstrate hands-on implementation of algorithms and techniques used in production self-driving systems, combining classical computer vision with modern deep learning approaches.
